# PureDOOM az AO-OS-en

A `PureDOOM.h` a Doom eredeti forrásának (id Software, 1993–1996, GPL v2 alatt újra kiadva 1999-ben)
egyfájlos, portolásra szánt változata (Daivuk, https://github.com/Daivuk/PureDOOM). Változtatás nélkül
használjuk; a licence a fájl fejlécében és a PureDOOM projektben található, és eltér az AO-OS többi
részétől. Az AO-OS-hez kötés a `user/doom.c` fájlban van. A shareware `doom1.wad` nem része a repónak:
a PC-n a `share/` mappába kell tenni, onnan a `fetch doom1.wad /state/games` viszi a netbookra.
